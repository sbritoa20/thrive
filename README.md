# Thrive

App personal para el celular (PWA) que junta tres cosas:

- **Trabajo**: horas con turno, horas sin turno y breaks, pagados a quincena vencida. También sirve para un trabajo con sueldo fijo.
- **Dinero**: lo que entra y sale cada quincena, ingresos extra, gastos y deudas con sus fechas de pago.
- **Gym**: rutinas con fotos de los ejercicios, calendario de asistencia y racha de lunes a viernes.

Los datos se guardan solo en el teléfono, nunca en este repositorio.

## Probar en el computador

```
node serve.js
```

Y abrir http://localhost:5173

## Publicación

GitHub Pages publica la carpeta `docs/` de la rama `main`.
